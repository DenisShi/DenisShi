Frontend developer with 4 years of commercial web development experience in React and TypeScript. I work on CRM systems and internal tools, the applications a company's own staff use all day to do their job.

My working rule: server state and client state are separate problems. Cached API data belongs in TanStack Query, UI state belongs in Redux, Zustand or Context. Mixing them is what makes a codebase slow to change.
